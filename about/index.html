02 / VALUES

사용자가 실제로 필요로 하고
지속적으로 사용하는 서비스를 만드는 개발자

기능 구현에 그치지 않고 사용자의 흐름을 설계합니다. 출시와 배포 이후에도 피드백을 바탕으로 문제의 원인을 찾고, 더 나은 경험으로 꾸준히 개선합니다.

01

출시와 운영

앱 5종을 App Store에 직접 출시했습니다.
심사 가이드라인과 로그인·신고·차단 정책에 대응하고,
배포 이후 업데이트까지 담당했습니다.

02

사용자 검증과 개선

전시회에서 200명 이상에게 서비스를 시연하고
60건 이상의 피드백을 수집했습니다.
TestFlight에서 발견한 오류를 수정하며
사용자 만족도 평균 9.15/10을 만들었습니다.

03

문제 원인 분석

SNAPY의 네트워크 구조를 분석하고
Kingfisher 캐싱과 Swift Concurrency로 병렬 처리를 적용했습니다.
이미지 표시 약 90%, 프로필 로딩 약 96%를 개선했습니다.

03 / STACK

Stack

  • SwiftUI와 MVVM을 활용해 iOS 및 Apple Watch 앱을 개발하고 기능 단위로 코드를 구성합니다.
  • Swift Concurrency와 Combine을 활용해 비동기 처리와 상태 업데이트를 구현합니다.
