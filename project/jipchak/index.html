    PROBLEM SOLVING

    문제 해결 과정

    SwiftUI와 Naver Map 상태 동기화

    Naver Map SDK가 UIKit 기반이라 SwiftUI 상태와 지도 이벤트를 직접 연결하기 어려웠습니다. 카메라 이동과 마커 선택이 즉시 반영되지 않아 지도와 매물 상세 정보가 어긋났습니다.

    UIViewRepresentable로 NMFMapView를 연결하고, updateUIView에서 좌표가 변경된 경우에만 카메라를 갱신했습니다. 지도 이벤트는 ViewModel의 @Published 상태로 전달해 일관되게 관리했습니다.

    PDF 파일 접근 및 업로드 안정성

    외부 PDF는 Security-Scoped Resource로 보호되어 직접 접근할 때 권한 오류가 발생했습니다. JSON과 PDF를 함께 보내야 해 일반 업로드 방식으로는 요청을 처리하기 어려웠습니다.

    PDF 형식과 크기를 먼저 검증하고 접근 권한을 획득한 뒤 파일을 읽도록 변경했습니다. Moya Multipart로 매물 정보 JSON과 PDF를 하나의 요청으로 전송해 잘못된 파일과 권한 오류를 사전에 처리했습니다.
