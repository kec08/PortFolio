    문제 해결 과정

    이미지 로딩 성능 개선

    사진 중심 서비스에서 AsyncImage는 캐시를 지원하지 않아 화면을 이동할 때마다 이미지 요청이 반복되고, 피드와 프로필에서 깜빡임과 지연이 발생했습니다.

    Kingfisher의 KFImage로 전환해 메모리·디스크 이중 캐시를 적용하고, 프로필 이미지에는 DownsamplingImageProcessor를 적용했습니다. 그 결과 이미지 표시 시간을 기존 300~500ms에서 10ms 이내로 줄여 약 90% 개선했습니다.

    프로필 로딩 시간 단축

    프로필 진입 시 앨범 목록을 먼저 조회한 뒤 각 앨범의 사진을 최대 31건까지 순차 요청해 응답 시간이 누적되었습니다.

    withTaskGroup 기반 병렬 처리로 앨범 상세 요청을 전환하고, 피드와 방명록 조회는 async let으로 함께 실행했습니다. 서버 구조를 바꾸지 않고 프로필 로딩 시간을 약 96% 단축했습니다.
